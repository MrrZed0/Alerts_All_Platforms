# Streamer.bot Multi-Platform Alert Studio Pro

A modular, zero-dependency alert overlay and visual customizer studio for streamers broadcasting across **Twitch**, **Kick**, **YouTube**, **Streamlabs**, and **StreamElements**.

This system pairs a local HTML5/Tailwind/Web Audio customizer studio with native Streamer.bot C# broadcast scripts, giving you 100+ animation entrance/exit effects, 100+ Web Audio synth chimes, customizable layouts, platform-adaptive shoutouts, and custom artwork background replacement.

---

## How To Use

* Download The Files Zipped Or Not
* Download Streamer.bot
* Open Import_Code from Streamer.bot Import Code Folder And Copy Everything
* Now In Streamer.bot Click On Import And Paste The Code And Click Ok
* Now Open customizer.html Inside Your Web Browser And Choose Your Settings And Looks
* Click On Export And Replace It With The overlay.html File
* Open OBS-Studio or Streamlabs And Add Browser Source
* Select The overlay.html File And Set Size To 1920x1080p Also Put Checkmark On Audio
